# Décryptage Express - production automatique
Chaque jour à 6h : choix du sujet -> script -> voix -> montage -> fichiers dans une Release.
Réglages : Settings > Secrets and variables > Actions (LLM_API_KEY, PEXELS_API_KEY ; variables LLM_BASE_URL, LLM_MODEL).
Test manuel : onglet Actions > "Vidéo du jour" > Run workflow.
